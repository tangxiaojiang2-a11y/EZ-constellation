站点配置

手机上用当前浏览器打开本页，填写 API Key 并保存。密钥存在这台手机的浏览器里，再回首页即可生成深度解读（同一浏览器才生效）。

正在读取本地配置…
  1. 1

    打开本页

    部署后地址是 https://你的域名/setup.html。本地预览也可以直接打开本页填写。

  2. 2

    填写并保存密钥

    选平台，填 API Key 后点保存。密钥保存在本机浏览器，无需管理员口令。

    豆包要填火山方舟的接入点 ID，一般以 ep- 开头。密钥保存在本机；部署到 Netlify 时会尽量同步到站点，方便全站调用。

  3. 3

    回到首页使用

    保存成功后打开 首页。用户只使用功能，「我的」里没有密钥配置。
