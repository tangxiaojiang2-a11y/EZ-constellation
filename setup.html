站长配置说明

普通用户只打开首页即可，无需进本页、无需填密钥。密钥由站长在 Netlify 配一次，全站开箱即用。

一次配置（推荐）

  1. 打开 Netlify → 你的站点 → Site configuration → Environment variables
  2. 新增下面三项（名字必须一致）：
    AI_API_KEY = 你的模型密钥
    AI_API_BASE = https://api.deepseek.com（或其他白名单平台）
    AI_MODEL = deepseek-chat
  3. 保存后到 Deploys → Trigger deploy → Redeploy（改环境变量必须重新部署）
  4. 部署完成后，用户打开首页即可自动深度解读，不用打开任何配置页

用户侧体验

首页、星座、起卦、塔罗等全部直接用站点密钥。失败时自动回退本地文案，不会让用户去填 Key。
